# Tatui Tur 🌍🎶

Este repositório contém um projeto de site semântico em **HTML5 e CSS3**, 
desenvolvido para estudos de **Front-End** e inspirado no turismo da cidade de Tatuí.

## ✨ Funcionalidades
- Estrutura semântica com HTML5 (`header`, `nav`, `main`, `section`, `article`, `footer`)
- Paleta de cores personalizada com variáveis CSS
- Responsividade com `media queries` e unidades relativas
- Estilo moderno com gradiente e sombra no título principal
